# TopoAnalysis — AI 3D 模型拓扑结构分析

对三维模型的拓扑结构进行**自动化算法检测 + 人工逐条审核 + AI 深度分析**三位一体的专业评测工具。内置四套分场景评测标准，覆盖实时渲染（游戏引擎）与离线渲染（影视动画）两大管线，支持静态/可动模型的差异化评分体系。

## 核心功能

### 1. 多标准评测体系

内置 **4 套专业评测标准**，覆盖不同应用场景：

| 标准 | 适用场景 | 维度数 | 准则数 |
|------|----------|--------|--------|
| 实时渲染·静态模型 | 游戏引擎中的场景、道具、建筑等静态资产 | 3 维度 | 11 项 |
| 实时渲染·可动模型 | 游戏引擎中的角色、生物等骨骼动画模型 | 4 维度 | 11 项 |
| 离线渲染·静态模型 | 影视动画、展示渲染中的静态资产 | 3 维度 | 11 项 |
| 离线渲染·可动模型 | 影视动画、VFX 中的可动模型 | 4 维度 | 11 项 |

每套标准的权重分配独立设计——实时渲染模型更强调面错误严苛度，可动模型额外增加**绑定动画友好性**维度。

#### 评测维度

- **面型质量**：四边/三角面比例、三角面分布合理性、极点分布（≥6 边共顶点）、N-gon 检测
- **面错误**：非流形边、重叠面、破洞面（边界边）
- **布线合理性**：结构跟随性、平坦区域面数控制、密度分布、循环线完整性
- **绑定动画友好性**（可动模型）：关节区域面数倾斜、可动部位环形线结构

#### 可选对称性评测

支持启用对称性维度——启用后自动调整各维度权重与准则满分，无需手动计算。对称性以 **YZ 镜面热力图** 呈现，定量分析模型拓扑的轴向对称程度。

---

### 2. 拓扑自动化分析引擎

基于 Three.js 底层几何数据，实现 **7 步递进式分析流水线**：

| 步骤 | 检测项 | 算法要点 |
|------|--------|----------|
| 面型分析 | 三角面/四边面/N-gon 统计 | 优先使用原始 OBJ 面数据（无需三角化），FBX 回退到 BufferGeometry |
| 非流形边检测 | 被 ≥3 个面共用的边 | 位置量化去重（0.1mm 精度），跨 Mesh 合并 |
| 重叠面检测 | 空间位置完全重合的面组 | OBJ 模式基于原始面索引 + 质心重合 + 3 顶点匹配；Geometry 模式基于三角化面 |
| 破洞检测 | 仅被 1 个面引用的边界边 | 与流形边共用边计数管线，取 count=1 者 |
| 极点分析 | valence ≥ 6 的顶点 | OBJ 模式基于原始拓扑邻接（精度最高），Geometry 模式基于三角化邻接 |
| 密度分布 | 逐顶点局部面密度 | 1/(1+平均邻接面面积)，min-max 归一化至 [0,1]，用于密度热力图渲染 |
| 循环线检测 | 闭合横向边环 | 顶点对边追踪算法——在顶点处寻找"对面边"，沿链行走至闭合，≥4 段视为有效环 |

所有自动检测结果在 3D 视口中以**彩色高亮叠加**展示：

- 🟠 三角面 → 橙色
- 🔴 N-gon → 红色
- 🟣 重叠面 → 紫色
- 🔵 极点 → 蓝色圆点
- 🔴 非流形边 → 红色线段
- 🟡 破洞边 → 黄色线段
- 🟢 循环线 → 绿色环带

---

### 3. 逐条审核打分流程

自动化检测后进入**人工逐条审核**——每个评测准则独立展开/收起，包含：

- 详细审核引导（根据模型类型动态生成观察要点）
- 分数滑块 + 档位快速选择（差 / 中 / 优）
- 3D 视图联动高亮（点击准则自动高亮对应拓扑特征）
- 对称性开关——可在打分流程中随时启用/关闭，权重和满分自适应调整
- 进度条实时显示：已评分项 / 总项数

提交时自动生成**结构化优化建议**：严重问题 / 警告 / 优点三分层，每条包含问题描述、原因分析、修复方案。

---

### 4. 模型浏览与对比

#### 3D 视口

- 支持 OBJ 格式上传（低模），FBX/OBJ（高模参考）
- **三种渲染模式**：线框 → 实体+线框混合 → 白模（默认混合模式）
- **对称参考面**：三轴可切换（左右 X / 上下 Y / 前后 Z），绿色半透明平面辅助观察
- 材质参数调节（颜色、粗糙度、金属度）
- 自动旋转、网格地面、接地适配
- 模型信息面板：顶点数、面数、包围盒、部件数、材质数

#### 模型对比

- **高低模对比**：低模在左（评测目标），高模在右（结构参考）
- 相机联动：两侧视口同步旋转/缩放/平移
- 低模侧独立高亮叠加，高模侧仅参考浏览
- **PK 对比**：两模型同维度得分差异分析 + AI 对比报告

#### 同屏 3D 对比（PK 模式）

- 两模型同时加载到同一视口
- 并行渲染，同步视角旋转
- 适用于教学展示和模型质量排名

---

### 5. 数据分析看板

- **雷达图**：多维度得分分布可视化
- **分数分布**：0-40 / 40-60 / 60-80 / 80-100 四段直方图
- **质量等级**：差 / 中 / 良 / 优 占比环形图
- **分类对比**：实时渲染 vs 离线渲染，静态 vs 可动
- **高频问题排行**：按严重程度列出常见缺陷及其改进建议
- 支持筛选：全部 / 示例模型 / 用户模型 / 实时渲染 / 离线渲染

---

### 6. AI 深度分析

模型评测完成后，支持调用 DeepSeek API 进行**专业级二次分析**：

- 基于评测得分 + 拓扑报告生成结构化分析文档（Markdown）
- 五级模型质量等级体系：S / A / B / C / D
- 逐维度得分归因 + 改进优先级排序
- 两模型 PK 对比分析
- 语调规范：专业、客观、冷静、中肯，禁止情绪化措辞

---

### 7. 教学对比模式

内置示例模型库，每个模型配备：
- 预设评测分数（真实逐条评分数据）
- AI 预分析报告
- 优化建议
- 3D 缩略图预览

提供**教学对比视图**：示例模型的评分与分析结果展示在可折叠面板中，供学习者对照参考。

---

### 8. 数据持久化

- **localStorage**：评测元数据（分数、维度得分、优化建议等）
- **IndexedDB**：OBJ 模型源文件（解决 localStorage 5-10MB 配额限制）
- 刷新页面后评测记录不丢失，模型可重新在报告页加载
- 支持模型删除（同步清理 localStorage + IndexedDB）

## 评分算法摘要

### 面数阶梯阈值（三角面比例）

| 标准类别 | 面数区间 | 优质线 | 合格线 |
|----------|----------|--------|--------|
| 实时渲染 | <15K | ≤30% | 30-40% |
| 实时渲染 | 15K-25K | ≤20% | 20-30% |
| 实时渲染 | >25K | ≤10% | 10-20% |
| 离线渲染 | <20K | ≤40% | 40-50% |
| 离线渲染 | ≥20K | ≤30% | 30-40% |

### 扣分规则

- N-gon：每 1 个扣 1 分，扣完为止
- 非流形边：每 1 条扣 1 分，扣完为止
- 重叠面：每 1 组扣 1 分，扣完为止
- 破洞边：每 1 条扣 1 分，扣完为止

### 总分计算

```
总分 = Σ(各维度得分) = Σ(维度内各准则得分)
准则得分 = round((人工评分 / 10) × 准则满分)
满分 = 100（所有标准统一满分）
```
